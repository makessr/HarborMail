## 新增

- 网页邮箱支持 Web Push 新邮件通知。通过 HTTPS 登录后，在「邮箱偏好 → 新邮件通知」为当前设备开启。即使邮箱标签页已关闭，支持的浏览器仍可显示系统通知。
- 通知只显示「你有一封新邮件」。点击可打开邮箱，锁屏上不会显示发件人、主题或正文。

## 升级说明

- 通知默认关闭，按设备开启。iPhone 和 iPad 需先将邮箱加入主屏幕，再从主屏幕打开并授权。
- 升级后会自动创建数据库表，VAPID 密钥和订阅继续由 SQLite 或 MySQL 保存。Docker 无需添加容器或端口，服务器需允许出站 HTTPS 访问浏览器推送服务。
- Linux 部署可下载 amd64 或 arm64 二进制，Windows amd64 用于本地开发。请使用 `SHA256SUMS` 校验下载文件。
