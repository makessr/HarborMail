## 邮箱与投递

- 邮箱账号可在网页设置中启用两步验证，并保存一次性恢复码。邮件客户端可使用应用密码。
- 邮件详情支持复制发件人和收件人地址。投递记录区分 MX 直投和 SMTP 中继，写信与草稿恢复流程也有改进。

## 协议与运维

- SMTP Submission 独立限制进程内并发邮件数和预留字节，并通过 Prometheus 暴露使用量和容量导致的临时拒绝。
- MySQL 上，已有 UID 的 IMAP 邮箱使用只读快照，减少全局 UID 锁等待。POP3 保存规范化邮件尺寸，启动后后台回填历史行。
- 单实例 MySQL Compose 升级脚本拉取 GHCR 的 `latest`，核对预期版本并保留旧镜像用于回滚。正式版仍提供 Linux 和 Windows 的 amd64、arm64 二进制。

已有部署请先备份数据库和配置。共享 MySQL 的实例建议顺序切换，先停止旧版写入，再启用新版。详见[生产运行手册](https://github.com/makessr/HarborMail/blob/v0.2.23/ops/README.md)。
