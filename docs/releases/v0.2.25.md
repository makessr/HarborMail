## 网页邮箱与账号管理

- 网页邮箱新增「修改密码」和一次性密码重置码。用户可在登录页通过预先保存的重置码找回密码。改密会撤销旧会话和应用密码，已有两步验证设置继续生效。
- 管理后台的账号详情提供改密和删除入口。旧版已清空但仍保留地址的邮箱可在「已回收」中释放地址，再创建同名空邮箱。
- 存储页默认列出各邮箱及其邮件和队列占用，点击邮箱可查看详情。操作审计的操作名称保持单行，后台列表和网页邮箱统一了空状态样式。

## 运维与升级

- 新增全量 Compose 的本机数据库备份、隔离回读和定时巡检模板，覆盖队列、存储空间和 inode、TLS 证书及扫描容器健康。备份和巡检需要管理员按部署环境安装和启用。
- 为 `mailqueue` 和 `mailstore` 增加直接单元测试，覆盖队列调度、重试以及邮件写入和回滚。
- 升级前备份数据库、配置和凭据。共享 MySQL 的实例应先停写再切换。下载资产包含 `SHA256SUMS` 和 Docker 镜像的固定摘要 `OCI_IMAGE`。参见[部署与升级](https://github.com/makessr/HarborMail/blob/v0.2.25/docs/deploy/common.md)和[生产运行手册](https://github.com/makessr/HarborMail/blob/v0.2.25/ops/README.md)。
