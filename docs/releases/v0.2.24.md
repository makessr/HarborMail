## 安全与协议

- 新安装默认启用每邮箱 1 GiB 硬配额，以及每日每账号 100 个、每域名 500 个外发收件人的额度。管理员可显式设置不限额。已有部署沿用原配置。
- SMTP 在 DATA 前检查连接总量、来源 IP 并发和速率，以及 RCPT 失败次数。网页认证的限流与数据库故障分别返回 429 和 503。
- 账号停用、强制退出、密码重置和应用密码撤销可断开存量协议连接。共享 MySQL 的实例通过邮箱修订通知同步撤销。
- 修复 POP3 退出时对已移出收件箱的邮件误更新草稿版本的问题。缩小 IMAP 删除标记、文件夹创建与重命名、标签删除的全局 UID 锁使用范围。

## 运维与升级

- 新增队列积压、失败增长、磁盘只读和 inode 不足告警。启动时为已有 SQLite 数据库补建审计索引。
- 新安装按发行标签选取同提交的 Docker 镜像，并把摘要写入配置。发行资产 `OCI_IMAGE` 提供固定摘要，校验值收录在 `SHA256SUMS`。
- 升级前备份数据库、配置和凭据。共享 MySQL 部署请先停掉旧实例的写入，再启动新版实例。固定摘要与 `latest` 的升级路径见[通用部署操作](https://github.com/makessr/HarborMail/blob/v0.2.24/docs/deploy/common.md)和[生产运行手册](https://github.com/makessr/HarborMail/blob/v0.2.24/ops/README.md)。
