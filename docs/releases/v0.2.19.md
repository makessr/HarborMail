## 部署与下载

- Compose 默认使用 GHCR 的 `latest` 镜像。首次安装可选择 Docker 命名卷或宿主机数据目录。
- 正式版同时提供 Linux amd64、Linux arm64、Windows amd64 和 Windows arm64 二进制。管理后台按运行平台和架构识别下载。
- README 增加实机演示、配置建议、部署和升级命令，以及极简版和标准版的测试数据。

## 许可证

- Harbor Mail 自有代码采用 Apache-2.0。
- 二进制和 Docker 镜像附带第三方许可证。GitHub Release 提供 `harbormail-licenses.tar.gz`、Alpine 对应源码归档和 `SHA256SUMS`。

已有 Docker 部署可从原项目目录运行 `docker compose pull && docker compose down && docker compose up -d`。沿用原数据目录和卷，执行 `down` 时请勿加 `-v`。
