## 新增

- 网页邮箱「邮箱偏好」首项可设置发件人显示名称，适用于主邮箱和已授权的发信别名。留空时只发送邮箱地址。

## 修复

- 首页登录后直接进入收件箱，首次配置和日常管理可从 `/admin` 登录。旧的 `/?view=mail` 链接会自动简化为首页地址。
- 修复发件人名称被引号包住时仍显示邮件头编码的问题，已经收到的邮件也能正确显示。

## 下载与升级

- Linux 提供 amd64 和 arm64 二进制，Windows amd64 供本地开发使用。请使用 `SHA256SUMS` 校验下载文件。
- Docker 部署请沿用已有 Compose 项目和数据卷。升级前备份，首次启动会自动为现有 SQLite 或 MySQL 邮箱偏好表补充显示名称字段。
